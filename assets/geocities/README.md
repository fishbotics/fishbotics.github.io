# GeoCities icon collection

Fifteen original pixel-art SVGs for Adam's personal site. Each uses a 48 × 48
coordinate grid, a transparent background, dark plum outlines, and a shared
palette of bright colors and beveled metallic highlights.

Open `index.html` to preview the collection at native or double size, on light
or dark backgrounds. Click any icon to open its SVG. The `background.svg` file
is a self-contained 715 × 1089 repeating tile, with the same three-column,
five-row ordering and icon centers as the original background. The dimensions
and positions match the existing dog and pizza photo tiles, so the hidden links
swap images in place. Icons are fully opaque, with transparent space between
them. This tile is the site's default background.

The SVGs contain vector paths, with no embedded raster images or external
resources. Use integer sizes such as 48 or 96 pixels for the crispest edges.

To edit the artwork, change the drawing coordinates or shared palette in
`scripts/build-geocities-icons.py` at the repository root, then run it with
Python and Pillow. The script regenerates all 15 SVGs and the background tile.
